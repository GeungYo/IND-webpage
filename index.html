문제

현재 보이는 방 모습만으로는 공간의 가능성을 알기 어렵습니다

방을 구하거나 인테리어를 바꾸려 할 때, 기존 가구와 물건이 놓인 상태 때문에 공간의 실제 넓이와 비워졌을 때의 느낌을 직관적으로 파악하기 어렵습니다.

해결

실제 공간을 스캔해 구조를 분석하고 변화된 모습을 미리 보여줍니다

사용자는 휴대폰으로 공간을 촬영한 뒤 결과를 업로드하고, 시스템은 구조물과 가구를 자동으로 구분해 비워진 공간과 재배치된 결과를 시각적으로 제공합니다.

핵심 기능

실내 공간 스캔 업로드

현재 배치된 가구를 제거하거나 새로운 위치로 옮긴 결과를 가상으로 미리 볼 수 있습니다.
